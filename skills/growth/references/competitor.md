# competitor — Competitor: sourced landscape analysis that surfaces a usable gap.

## Intake

- Direct and indirect competitors to analyze
- Dimensions that matter (positioning, pricing, features, model)
- Your current standing and strengths
- Decision the analysis must inform
- Default stack: Twenty CRM competitor records where available, else any CRM or notes.

## Deliverable

A competitor analysis: a landscape map (direct/indirect/substitutes), a feature/positioning/pricing comparison, each competitor's weakness, and the actionable gap/opportunity — with sources and dates.

## Procedure

1. Define the decision the analysis informs; analysis without a decision is trivia.
2. Identify competitors: direct, indirect, and substitutes (including 'do nothing').
3. Compare on dimensions that matter to the buyer, not every feature.
4. Read their positioning and pricing pages; note claims and proof.
5. Find each competitor's structural weakness (model, segment, service).
6. Surface the gap your business can credibly own.
7. Cite sources with dates; flag anything inferred vs confirmed.
8. Turn the gap into a recommendation tied to positioning.
9. Resolve each named hypothesis as confirmed/contradicted/unresolved, citing the row that drove the call.
10. Attribute-check every cited move: verify the source names the target — industry-wide coverage cross-attributes to the wrong rival.
11. Pull the spine for every rival (firmographics, funding, workforce trajectory, owned-channel voice); add purpose-conditional depth only; mark sections skipped-vs-empty so gaps read as investigated, not missed.
12. Monitor on cadence (daily for moves, weekly for synthesis) with per-dimension alert thresholds against baselines; publish a recurring brief.
13. Measure share-of-voice across four dimensions: organic, paid, social, AI-citation.
14. Every ongoing monitor plan ships pause/disable/delete steps alongside the cadence — a delivered alert never triggers an automatic write.
15. For social benchmarking, snapshot followers/bio per rival, pull recent posts, sort by engagement, and table handle/followers/avg engagement/top post — engagement rate = (likes + reposts + replies) / followers, plus posts/day.
16. Mine ad libraries (Meta Ad Library / LinkedIn ads) for live rival creatives: capture, group by theme/audience/format, surface proven patterns → paidads audit for creative teardown.
17. Shape each gap recommendation as what-changes + why (cited evidence) + how to verify — no recommendation ships without a re-check step.
18. Refresh the social picture on cadence: last-7-day stories per niche with verified dates and links; score rival posts by engagement (reactions + 3×comments) and extract top/bottom-decile hook and format patterns.
19. Re-verify each cited rival move fresh before publishing — never assert from memory or a stale snapshot; a source checked last week is a hypothesis, not a fact.
20. Persist evidence in a dated raw-data lake (source: marketingskills `competitor-profiling` SKILL.md): `competitor-profiles/raw/<slug>/<YYYY-MM-DD>/{scrapes,seo,reviews}` — never overwrite; Firecrawl Map→Scrape pipeline per page with an extraction matrix; cross-check site claims against traffic/backlink scale; keep one profile doc per competitor plus a `_summary.md` roll-up.

## Quality gate

- [ ] Analysis tied to a decision.
- [ ] Direct, indirect, and substitutes covered.
- [ ] Compared on buyer-relevant dimensions.
- [ ] Each competitor's weakness identified.
- [ ] Gap is credible and actionable.
- [ ] Sources cited with dates; inferences flagged.
- [ ] Named hypotheses resolved (confirmed/contradicted/unresolved) with citations.
- [ ] Every cited move attribute-checked to the target.
- [ ] Skipped-vs-empty sections marked.
- [ ] Monitoring cadence set with per-dimension thresholds vs baselines and a recurring brief.
- [ ] Share-of-voice scored on organic/paid/social/AI-citation.
- [ ] Each recommendation states what, why (cited), and how to verify.
 - [ ] No rival move asserted from memory or a stale snapshot; every claim re-verified fresh.
 - [ ] Raw evidence lake dated and append-only with claim cross-checks; per-competitor docs + summary current.

## Routing

- Social-listen reporting → smm analytics mode for the reach-to-outcome funnel and next-cycle actions.
- Ad-library creative patterns → paidads audit mode for teardown.
- Rival social-post drafting from the benchmarked patterns → smm content mode.
- Moves that fail re-verification → growth positioning mode for the gap re-check without the claim.
