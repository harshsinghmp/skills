# funnels — Funnels: map acquisition → conversion → retention, then fix the weakest stage.

## Intake

- Current funnel stages and conversion rates
- Traffic sources per stage
- Known drop-off points and their causes
- Targets (CAC, conversion, LTV)

## Deliverable

A funnel map: stages with volumes/rates, the biggest leak, prioritized improvements per stage, and the metric each improvement should move — plus a measurement plan.

## Procedure

1. Map the current funnel end to end: awareness → interest → consideration → conversion → retention → referral.
2. Put numbers on each transition; find the biggest drop-off with enough volume.
3. Diagnose the cause at that stage (message, friction, trust, offer, timing).
4. Prioritize fixes by impact × effort; start with the weakest stage, not the shiniest.
5. Assign each fix the metric it moves and how it's measured.
6. Define the offer/lead-magnet per stage where needed.
7. Set a review cadence; fix one stage at a time to attribute impact.
8. Quantify leaks in order: multi-model comparison first, then assisted-conversion ratios, then path-length and time-to-convert distributions.

## Quality gate

- [ ] Full funnel mapped with numbers per transition.
- [ ] Biggest leak identified (with volume).
- [ ] Causes diagnosed, not guessed.
- [ ] Prioritized improvements with metrics.
- [ ] Measurement plan defined.
- [ ] Leak quantified via model comparison, then assisted ratios, then path/time distributions.
- [ ] No channel execution here — routed to the relevant tool.
