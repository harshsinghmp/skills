# 07 — Design High-Value Empty States

An empty state is the first thing a new user sees. A blank, lifeless page feels broken; a great empty state acts as an intuitive on-ramp.

---

## 1. The 4-Part Anatomy of an Empty State

1. **Illustrative Anchor / Icon**: A muted, friendly icon or subtle illustration (`w-12 h-12 text-muted-foreground/60`).
2. **Clear, Positive Heading**: "No projects yet" or "Your inbox is clear".
3. **Actionable Description**: 1–2 sentences explaining what this screen will contain and why creating one is beneficial.
4. **Direct Primary CTA**: A high-contrast button that lets the user take immediate action ("Create Your First Project", "Import Data").

---

## 2. Empty State Anti-Patterns to Avoid

- ❌ Displaying a raw empty table with header columns and blank rows.
- ❌ Showing a confusing error icon (e.g., a red exclamation mark) when no data exists.
- ❌ Leaving the page completely blank without any instructional copy.
- ❌ Hiding the creation button in a distant top-right corner; place the CTA centered in the empty state itself.
