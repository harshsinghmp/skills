# 🔬 research — Client Research Department

Research for a client's product, market, and counterparties. Method-matched user research, recency-windowed market pulse, and hypothesis-forced due-diligence dossiers — every artifact cited, decision-ready, and routed to evidence-ledger for reuse.

- **user-research** — plan and run method-matched user research (interviews, usability, JTBD, surveys) with sample/saturation sizing and recurrence-gated insights.
- **market-pulse** — recency-windowed category/competitor briefing with sentiment, trend, and launch-timing signals.
- **entity-dossier** — hypothesis-forced due-diligence dossier: verdict, 12-month timeline, red flags, provenance audit.
- **audit** — source/citation audit of any research artifact; BLOCK/REJECT/PROPOSE-DIFF findings.

Install: `npx skills add harshsinghmp/muse-skills --skill research`
