# objection — Honest objection-handling handbook.

## Scope

- The buyer and the purchase context.
- Real objections from win/loss, sales calls, competitor teardowns, reviews.
- Where each objection shows up in the funnel.

## Deliverable

An objection handbook: per objection — the buyer's real concern, an honest answer (no dodging), a proof point, and a graceful pivot if the deal genuinely does not fit.

## Procedure

1. Collect objections from real buyer language (calls, win/loss, reviews), not invented friction.
2. Group and rank them: frequency × deal impact decides the top objections to cover.
3. For each: state the buyer's real underlying concern (price, risk, switching cost, trust, competitor).
4. Answer honestly — "we're different" with no reason is not an answer.
5. Attach one verifiable proof point per objection.
6. Add a disqualify signal: when this objection is real, say no gracefully and save both sides' time.

## Quality gate

- [ ] Objections sourced from real buyer language.
- [ ] Each maps to an underlying concern, not a surface excuse.
- [ ] Answers are honest with a verifiable proof point.
- [ ] Disqualify signals present, not forced-fit answers.

## Routing

- Pricing objections → `growth` (pricing mode).
- Competitor objections → `growth` (competitor mode) / `research`.
