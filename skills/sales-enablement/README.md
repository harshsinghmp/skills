# 🤝 sales-enablement — Pre-Sale Sales Enablement Department

Sales assets that help a client's team win deals: outcome-led demo scripts, honest objection handbooks, scannable one-pagers, and sales playbooks — all grounded in real buyer objections and consistent with growth positioning.

- **demo** — outcome-led demo script/narration with pause points and proof.
- **objection** — honest objection-handling handbook keyed to real buyer concerns.
- **one-pager** — one scannable page that sells the outcome in 60 seconds.
- **playbook** — sale stages, scripts, disqualify rules, and pitch paths.
- **audit** — audit existing assets for buyer truth and consistency.

Install: `npx skills add harshsinghmp/muse-skills --skill sales-enablement`
