# links — Links: profile analysis, earned-link acquisition, toxic-link triage.

## Intake

- Current backlink profile (tool export)
- Linkable assets (data studies, tools, guides)
- Outreach capacity (who writes/sends)
- Risk tolerance (manual-action history?)
- Default stack: Ahrefs free tier (or proprietary equivalent).

## Deliverable

Link plan: profile analysis (anchor distribution, referring-domain quality, competitor gaps), asset priorities (what earns links), outreach campaign briefs, and a disavow decision (only where warranted) with rationale.

## Procedure

1. Analyze the profile: referring domains by quality tier, anchor distribution (over-optimized money anchors = risk).
2. Gap against competitors: which linking domains they have that the client can legitimately earn.
3. Prioritize linkable assets: original data, tools, definitive guides — links are earned by assets, not asked-for.
4. Design outreach: relevance-first short pitches, no mass blasts; digital-PR angles for newsworthy data.
5. Track acquisition like a funnel: prospects → responses → placements; review monthly.
6. Toxic links: only disavow with a manual action or clear toxic pattern; document evidence for each batch.
7. Unlinked mentions: claim existing brand mentions (fastest legitimate win).
8. Score backlink gaps weighted by authority, multi-competitor overlap, traffic, and relevance; require overlap on 2+ competitors before prioritizing.
9. Run broken-link and unlinked-mention fast lanes before any cold outreach.

## Quality gate

- [ ] Anchor distribution reviewed for over-optimization.
- [ ] Acquisition targets relevance-first (no PBN/submit-all schemes).
- [ ] Assets chosen are genuinely linkable, not repackaged posts.
- [ ] Outreach is 1:1 quality, not mass-blast.
- [ ] Disavow only with documented evidence.
- [ ] Gap targets scored (authority x overlap x traffic x relevance) with 2+ competitor overlap.
- [ ] Fast lanes (broken-link, unlinked mentions) exhausted before cold outreach.
