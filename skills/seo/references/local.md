# local — Local SEO: GBP optimization, citations, NAP consistency, local pages.

## Intake

- Locations and service areas
- GBP access status (claimed, verified)
- Current citation set (Apple, Bing, Yelp, industry directories)
- Review state (count, rating, velocity)
- Default stack: Whitespark/BrightLocal, Yext (or proprietary equivalent).

## Deliverable

Local plan: GBP optimization spec (categories, services, description, photos, posts), NAP audit across the citation set with corrections, review-generation plan, and local landing-page structure (one page per service area where legitimate).

## Procedure

1. Audit GBP: primary category match, secondary categories, services, description keywords, geotagged photos.
2. NAP audit: exact-match name/address/phone across GBP, site footer, and top citations; correct mismatches.
3. Reviews: plan generation (post-service ask, QR/link), response templates for +/- reviews, velocity targets.
4. Local pages: one per physical location (legit only — no doorway pages); location schema with sameAs.
5. Local content: service × city pages where each is genuinely unique; consolidate thin duplicates.
6. GBP posts cadence: offers/events/updates weekly; Q&A seeded with real FAQs.
7. Track maps rankings separately from organic (different SERP, different levers).
8. Score visibility 0-100: NAP exact-match audit, citation triage, per-section completeness; emit top-5 quick wins and a 90-day plan.

## Quality gate

- [ ] Primary GBP category is the best-fit, not just plausible.
- [ ] NAP exact-match across the top citation set.
- [ ] Review plan compliant with platform policies (no incentivized reviews).
- [ ] Location pages each have unique substantive content.
- [ ] Maps rankings tracked separately.
- [ ] Visibility scorecard 0-100 recorded with top-5 quick wins and 90-day plan.
