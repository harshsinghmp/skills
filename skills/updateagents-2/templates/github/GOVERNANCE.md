# Governance — {{PROJECT_NAME}}

## Roles

- **Project owner/maintainers:** set project direction, review contributions, and make release decisions.
- **Contributors:** propose, implement, document, and verify changes.
- **Configured AI agents:** assist under the project's `AGENTS.md`; a human owner remains accountable for approvals and external actions.

## Decisions

Small reversible changes may be reviewed in their pull request. Changes to project scope, architecture, security policy, governance, or release behavior should be discussed with the owner before implementation and recorded in the project decision log when durable.
