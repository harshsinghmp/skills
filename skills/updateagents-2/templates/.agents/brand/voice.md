# 🗣️ Brand Voice & Editorial Guidelines — {{PROJECT_NAME}}

> **Operating Directive**: Every piece of copy, documentation, social post, and user-facing interface text must reflect these voice rules. Tone scales with context, but brand character remains consistent.

---

## 1. Brand Voice Dimensions

| Dimension | Scale (1–10) | Description & Manifestation |
| :--- | :--- | :--- |
| **Formality** | `4 / 10` | Conversational, approachable, professional without corporate stiff-neck. |
| **Directness** | `9 / 10` | Answer-first. Bottom line up front (BLUF). Zero filler or preamble. |
| **Humor** | `3 / 10` | Dry wit and subtle levity allowed; never slapstick, sarcastic, or forced. |
| **Technical Depth**| `8 / 10` | Precise and authoritative. Use exact terminology; explain without condescending. |
| **Energy** | `7 / 10` | Confident, forward-moving, and pragmatic. Biased toward action. |

---

## 2. Vocabulary Do's & Don'ts

| Do Use (Concrete & Grounded) | Don't Use (Vague & Inflated) | Rationale |
| :--- | :--- | :--- |
| *Shipped, built, deployed, verified* | *Leveraged, utilized, synergized* | Active verbs with tangible outcomes beat passive corporate buzzwords. |
| *2.4x faster, 140ms latency, zero dependencies* | *Blazing fast, lightning speed, lightweight* | Quantifiable metrics build credibility; vague adjectives destroy it. |
| *Works with your existing tools* | *Revolutionary paradigm shift* | Respects user intelligence; avoids inflated marketing claims. |
| *Simple, modular, tested* | *Next-generation, best-in-class* | Clean descriptions state what it is without empty self-praise. |

---

## 3. Anti-Puffery Blacklist

Never generate copy containing these prohibited marketing clichés:

- ❌ *"Revolutionary"* / *"Game-changing"* / *"Disruptive"*
- ❌ *"Cutting-edge"* / *"State-of-the-art"*
- ❌ *"Harness the power of"* / *"Unlock the potential"*
- ❌ *"In today's fast-paced digital world..."*
- ❌ *"Seamlessly integrate"* (demonstrate integration in one code snippet instead)
- ❌ *"Look no further"* / *"Needless to say"*

---

## 4. Cadence & Readability Standards

- **Target Grade Level**: 7th to 8th grade (Flesch-Kincaid) for web copy and marketing; technical docs prioritize clarity over syntactic complexity.
- **Rhythm**: Vary sentence length. Combine punchy 4-word statements with detailed explanatory compound sentences. Avoid monotonous rhythm.
- **The 18-Token Standalone Rule**: Key value propositions, headers, and bullet points must deliver complete, quote-ready meaning within 18 words without requiring surrounding paragraphs for context.

---

## 5. Channel-Specific Voice Adaptations

- **Technical Documentation & Code**: Objective, clinical, evidence-backed. No exclamation points. Code snippets precede explanation.
- **Marketing Website & Landing Pages**: Benefit-led, problem-aware, conversion-focused. Speaks directly to the user (*"You get..."* vs *"Our platform offers..."*).
- **Social Media (X / LinkedIn)**: Punchy opening hooks, high-density insights, white space between thoughts, minimal hashtags (max 2-3).
- **Transactional Notifications & Emails**: Direct, reassuring, with an unambiguous single call to action.
