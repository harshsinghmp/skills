## 3. Platform Distribution Standards

- **LinkedIn**:
  - First 2 lines must create a curiosity gap (above the *"see more"* fold).
  - Generous whitespace; 1–2 sentences per paragraph.
  - End with a thought-provoking question to stimulate comments.
  - Zero external links in the main post body (keep in first comment or bio).
- **X (Twitter)**:
  - First tweet must stand alone as an undeniable truth or bold hook.
  - Numbered threads (`1/X`) with code snippets, GIFs, or screenshots.
  - Final tweet recaps the main takeaway and provides an actionable CTA.
- **Email Newsletter / Digest**:
  - High-signal executive summary at the very top.
  - Direct, warm, personal tone (from founder to reader).
  - Clear, single primary link / action.
