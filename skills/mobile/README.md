# 📱 mobile

The mobile department head: one skill, five modes — ios, android, cross, pwa, aso. Stack-honest path selection, then platform-native delivery discipline.

## Install

```bash
npx skills add harshsinghmp/muse-skills --skill mobile
```

## Use

Describe the task in plain language; the frontmatter triggers discovery:

```text
Convert our Astro site to an iOS app with push notifications.
```

```text
Build a React Native inventory app with offline barcode scanning.
```

## Modes

| Mode | Request it with | Deliverable |
|:---|:---|:---|
| **ios** | native iOS (SwiftUI) | iOS: SwiftUI-first, HIG compliance, App Store submission discipline. |
| **android** | native Android (Compose) | Android: Jetpack Compose, Material 3, Play Store release discipline. |
| **cross** | cross-platform (Expo/React Native/Flutter) | Cross-platform: Expo for React teams, Flutter for fresh starts — one codebase, both stores. |
| **pwa** | PWA conversion | PWA: installable, offline-capable web app — service worker, manifest, storage strategy. |
| **aso** | app store visibility (ASO) | ASO: keyword optimization, listing assets, ratings loop, review responses. |

## How it works

1. **Intake** — the department gate in SKILL.md Quick Reference.
2. **Mode resolution** — one mode per run; only its reference loads (token-efficient).
3. **Execute** — the mode playbook in `references/`.
4. **Gate** — verification checklist before delivery.
