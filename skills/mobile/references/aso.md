# aso — ASO: keyword optimization, listing assets, ratings loop, review responses.

## Intake

- Current store listings (both stores) + conversion stats
- Competitor apps and their positioning
- Keyword universe (what do users search?)
- Ratings/review state and velocity

## Deliverable

ASO plan: optimized titles/subtitles/keywords per store, screenshot/preview asset briefs, ratings-generation plan, review-response templates, and a measurement plan (impressions → conversion → installs).

## Procedure

1. Keyword research per store (App Store keyword field vs Google Play title/description indexing).
2. Rewrite the listing: title (brand + top keyword), subtitle/short description carrying the value prop.
3. Screenshots: first 2 carry the hook (most users see 2); caption each with benefit, not feature.
4. Ratings loop: in-app prompt at the moment of success (after achievement, never on interrupt) — never incentivized.
5. Review responses: templates for praise/issues; responses are public ASO surface.
6. Localization: highest-ROI languages first (listing text, not the whole app).
7. Measure: impressions, product-page conversion, install velocity; iterate monthly.

## Quality gate

- [ ] Keywords placed per each store's actual indexing rules.
- [ ] First 2 screenshots carry the value prop.
- [ ] Ratings prompt timed at success moments (policy-compliant).
- [ ] Review-response templates ready.
- [ ] Measurement loop defined with monthly iteration.
