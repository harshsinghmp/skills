# referral-rebuy — Referral or repurchase offer: compound the win.

## Scope

- The referral or repurchase/renewal offer made after value is proven — never before.
- Feeds: the repurchase playbook gap is real (corpus has only a name-only repurchase strategy — proves the gap, not a dependency); the offer pattern lives here.
- One offer per cycle; stacking referral + rebuy + review in one message burns goodwill.

## Deliverable

A single timed offer — referral ask or repurchase/renewal proposal — sent after proven value, with terms simple enough to say yes to in one reply.

## Procedure

1. Confirm value proven: value-note history, positive QBR, or review left — none of these → hold the offer.
2. Pick one: referral ask (happy + connected client) or repurchase/renewal (expiring scope, adjacent need) — never both at once.
3. Make saying yes trivial: pre-drafted intro line for referrals; scoped renewal terms for rebuy (scope, price, start).
4. Send, log, follow the silence rule: one nudge max, then back to heartbeat.
5. Closed referral/rebuy routes to `ops` (new SOW) — this mode opens, `ops` closes.

## Quality gate

- [ ] Value proven before offer (note, QBR, or review on record).
- [ ] Exactly one offer per cycle (referral or rebuy, not both).
- [ ] Yes-path trivial (draft or scoped terms included).
- [ ] Won offer handed to `ops` as new SOW input.

## Routing

- Won offer → `ops` win/sow mode (signed SOW + deposit motion).
- Pricing the renewal → `growth` pricing mode.
- Outreach wording at scale → `gtm` outreach mode.
