# socials — Social design system: profile kit, post templates per format, grid rhythm.

## Intake

- Platforms and the formats used on each (feed, story, cover, video thumb)
- Brand tokens (from `branding` or client doc)
- Content pillars (what gets posted)
- Safe-zone specs per platform

## Deliverable

Profile kit (avatar, covers/banners per platform at exact dims), post templates per format (feed, story, carousel cover), series/grid rhythm rules, and export specs per platform.

## Procedure

1. Lock platforms and exact dimensions per asset type (they change — verify current specs).
2. Apply brand tokens: color, type, spacing; define the layout anatomy per template.
3. Design the profile kit first (avatar must survive circular crop).
4. Build one template per content pillar × format; keep a shared grid.
5. Define the grid rhythm: alternating emphasis so the profile reads as a system.
6. Export spec: format, dims, safe zones for UI overlays, file naming.

## Quality gate

- [ ] Safe zones respected (text clear of platform UI overlays).
- [ ] Text at or above platform legibility minimums.
- [ ] Every template built from brand tokens — no one-offs.
- [ ] Grid preview (9-tile) reads coherent.
- [ ] Avatar legible at 24px and inside circular crop.
