# logo — Logo design: brief → concept territories → refinement → variants and usage rules.

## Intake

- Brand personality (3–5 adjectives) and positioning
- Competitors' marks (to be distinct from)
- Applications (favicon 16px, app icon, print, merch)
- Color constraints; lifespan (avoid trends if the brand must last)

## Deliverable

2–3 concept territories with rationale, a refined direction, the full variant set (primary, stacked/lockup, icon/monogram, mono, reversed), clear-space + minimum-size rules, and a usage sheet. Vector spec + raster previews.

## Procedure

1. Write the brief: personality, positioning, audience, applications, taboos.
2. Scan competitor marks; name what to avoid (shape, color, cliché).
3. Explore 2–3 concept territories; state the story of each in one line.
4. Refine the chosen direction: geometry, optical balance (not mathematical center), spacing rhythm.
5. Build the variant set: primary, lockup, icon, mono, reversed.
6. Define clear space (x-height rule), min sizes, and misuse list (stretch, recolor, drop shadow).
7. Deliver vector spec (construction notes) + previews at 16/32/128px.

## Quality gate

- [ ] Legible and distinct at 16px in mono.
- [ ] Clearly distinct from every competitor mark shown at intake.
- [ ] Full variant set present, not just the hero lockup.
- [ ] At most 2 colors + mono; works on light and dark.
- [ ] Usage sheet covers clear space, min size, and misuse.
