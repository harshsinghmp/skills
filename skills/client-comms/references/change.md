# change — Change-request triage: impact, options, scoped approval before work.

## Intake

- The requested change in the client's words
- Current scope (SOW/milestone it touches)
- Effort estimate path (who sizes it)

## Deliverable

Change note: in-scope or out-of-scope ruling, impact (effort/cost/date), options (do / defer / descope swap), and written approval before any work starts.

## Procedure

1. Rule first: in-scope (covered by SOW) or out-of-scope — state which, with the SOW line cited.
2. Size the impact: effort, cost delta, date delta. No work starts on estimates alone.
3. Offer options: do now (approved CR), defer to next milestone, or swap against lower-priority scope.
4. Get written approval (email/CR doc) recording scope, cost, and date impact; file in the client record. Verbal yeses do not count.

## Quality gate

- [ ] In/out-of-scope ruling with SOW citation.
- [ ] Impact stated in effort, cost, and date.
- [ ] Written approval filed before work starts.

## Routing

- Pricing the CR → `growth`; internal resourcing → `ops`; the extra work itself routes to its skill.
