# feedback — Client feedback intake: structured capture, triage, and response plan.

## Intake

- Raw feedback (review call, email, survey, NPS)
- What milestone it targets
- Response owner and deadline

## Deliverable

Feedback triage: each item Accepted (routed with owner), Declined (reason stated), or Clarify (question back) — plus a client-facing response covering all three.

## Procedure

1. Capture verbatim first, then group by theme — never summarize away the client's words before triage.
2. Triage each item: Accept (route to owning skill with a ticket), Decline (state the reason honestly — scope, evidence, tradeoff), Clarify (ask the narrowest question that unblocks).
3. Respond covering every item; declines stated plainly with the tradeoff named, not softened into silence.
4. Feed systemic items into `ops` retro; satisfaction trends into `growth`.

## Quality gate

- [ ] Every item triaged — none dropped silently.
- [ ] Declines state reasons, not excuses.
- [ ] Client response covers all items.

## Routing

- Accepted work routes to its skill; systemic fixes → `ops`; positioning fallout → `growth`.
