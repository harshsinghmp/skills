# audit — Account audit: structure, tracking, creative, budget — findings with evidence.

## Intake

- Account access / export or screenshots
- Time window (last 90 days default)
- KPI baseline (target CPA/ROAS, historical)
- Business changes in the window (pricing, offers, site)
- Default stack: native ad managers + open-source reporting (no proprietary suite assumed)

## Deliverable

Audit report: structure review (campaign/object mapping), tracking verification (events firing, UTM discipline), creative analysis (fatigue curves, variant winners), budget/pacing review, prioritized findings with evidence citations, and a 30-day action plan.

## Procedure

1. Verify tracking integrity first — if events are broken, everything else is fiction.
2. Map current structure vs the doctrine (objective → object mapping, theme segmentation).
3. Pull the KPI baseline; identify the divergence point (when did CPA rise / ROAS drop?).
4. Creative audit: score each creative 0–100 for fatigue vs its 7–14 day baseline (frequency + CTR + CVR decay); estimate days-until-fatigue per top spender and flag refresh before it crosses.
5. Audience audit: overlap, exclusions present, burn segments.
6. Reallocate by marginal efficiency: rank channels/ad sets by incremental return per next unit of spend, shift budget down that ranking until each hits its saturation ceiling (returns flatten); enforce a minimum viable spend floor per channel before any cut so losers keep signal.
7. Phase reallocation over 4–8 weeks with weekly checkpoints; rollback trigger: revert the week's shift if blended CPA/ROAS degrades beyond tolerance two checkpoints running.
8. Pacing check: flag overpace above 110% and underspend below 70% of the pacing curve; project end-of-period spend from daily burn and correct before the period closes.
9. Hold back 10–15% contingency; deploy only on pre-defined triggers (winner needs scale, seasonal spike, emergency cover) — never to plug leaks.
6. Correlate with business changes (offer/site/pricing changes explain many 'account problems').
7. Rank findings by spend impact; write the 30-day plan with owners and expected effect.

## Quality gate

- [ ] Tracking verified before conclusions drawn.
- [ ] Every finding cites its metric and window.
- [ ] Divergence point identified, not just 'it got worse'.
- [ ] Findings ranked by spend impact.
- [ ] Action plan has owners and dates.
