# retargeting — Retargeting: audience pools, frequency caps, cross-channel funnels.

## Intake

- Audience sources (site pixel, customer list, engagers)
- Segments (viewed product, cart, pricing page, churn-risk)
- Offer per segment (discounts leak margin — decide consciously)
- Frequency caps and window lengths

## Deliverable

Retargeting plan: segment definitions with events and windows, channel mapping (which platform retargets which segment), offer/exclusion matrix, frequency caps, and burn/exclusion logic (converted users removed).

## Procedure

1. Define segments by behavior depth: viewer → engager → cart/pricing → lapsed.
2. Exclude converts everywhere — paying to chase customers is the #1 retargeting waste.
3. Map channels: Meta/dynamic product ads for carts; Google RLSA for high-intent; LinkedIn for B2B engagers.
4. Sequence messages by stage: social proof → objection handling → offer (only at the bottom).
5. Cap frequency (2–3/week display, tighter on social) — fatigue is retargeting's default state.
6. Set window lengths by sales cycle (14–30d e-com, 30–90d B2B).
7. Decide discounts deliberately: a cart-abandon coupon leaks margin; test against a no-offer control.

## Quality gate

- [ ] Converted users excluded from every segment.
- [ ] Message sequence differs by stage.
- [ ] Frequency caps set per channel.
- [ ] Windows match the sales cycle.
- [ ] Discount strategy is a decision, not a default.
