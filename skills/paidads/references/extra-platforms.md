# extra-platforms — Secondary paid platforms: Microsoft, Pinterest, X, Apple Search, retail media, native, audio, CTV/DOOH, Local Services. The eight primary modes own the core spend. This mode extends the same doctrine (objective before budget, audience before creative, tracking before launch) to secondary platforms. Graduate a platform to a full mode when it holds sustained standalone budget. ## Intake - Which platform and why it fits the audience (not novelty) - Native account access + conversion tracking status - Budget floor for the platforms auction to exit learning ## Deliverable Platform launch note: native object map, one targeting rule, one gotcha, spend floor, and the graduation threshold — or a no-go with reason. ## Procedure 1. Confirm audience fit first — a platform without the audience is a no-go, recorded with reason. 2. Map the doctrine to native objects per the platform notes below; verify tracking before any spend. 3. Set the platforms spend floor; below it, consolidate into a primary channel instead. 4. Review quarterly: sustained standalone budget → graduate to a full mode. ## Platform notes - Microsoft/Bing — Search import from Google Ads first, then differentiate (LinkedIn-profile targeting is the edge). Gotcha: volume is a fraction of Google; judge on CPA, not scale. - Pinterest — Discovery mindset, long consideration windows; catalog-style evergreen creative. Gotcha: attribution lags; use longer windows. - X — Interest and keyword targeting; brand-safety controls mandatory. Gotcha: volatility — cap test budgets and watch placement reports. - Apple Search — Exact-match brand plus competitor conquest; tiny surface, high intent. Gotcha: small keyword pool; over-segmentation kills learning. - Amazon plus retail media — Bottom-funnel intent; campaigns map to SKUs, not keywords. Gotcha: retail readiness (reviews, stock) gates everything. - Native (Taboola/Outbrain) — Arbitrage only works with real LTV math. Gotcha: whitelist placements aggressively. - Audio (Spotify etc.) — Weak click attribution; measure with promo codes and brand-lift proxies. Gotcha: never judge on last-click ROAS. - CTV/DOOH — Frequency discipline is the whole game. Gotcha: set frequency caps day one. - Local Services — Pay-per-lead; profile completeness outranks bidding. Gotcha: lead disputes need a documented credit process. ## Quality gate - [ ] Audience fit stated or no-go recorded. - [ ] Tracking verified before spend. - [ ] Spend floor named; below-floor spend consolidated. - [ ] Graduation threshold written for any platform kept. ## Routing Primary-channel work → that channels mode; account-wide issues → audit; landing pages → webdev plus refactor-ui. ## Sources Reference URLs provided for this mode are listed here.
