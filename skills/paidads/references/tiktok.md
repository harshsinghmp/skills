# tiktok — TikTok Ads: creative-first, Spark ads, rapid-fatigue management.

## Intake

- Creative concept (native-first, hook < 3s)
- Creator partnerships if using Spark
- Objective and event (complete TikTok pixel first)
- Refresh cadence budget (creative fatigue hits fast)

## Deliverable

Campaign structure: ad groups by audience/bid, 3–5 native-style creatives with hooks and CTAs, Spark ad setup plan (creator codes), refresh schedule (new creative every 7–14 days), and the TikTok pixel/event mapping.

## Procedure

1. Install TikTok pixel and define events before anything else.
2. Concept 3–5 native creatives: hook < 3s, UGC/creator style, vertical 9:16.
3. Spark ads: get creator video codes to run from real posts (boosts trust + comments).
4. Structure ad groups: broad audience + algorithm trust; narrow only for tests.
5. Bid: start Max Conversions (low bid to cap CPC), scale budget 20% steps.
6. Schedule creative refresh every 7–14 days — fatigue is the channel's tax.
7. Read the funnel: 6s views → CTR → conversion; fix the first failing stage.
8. Test one variable at a time in an isolated grid (hook/CTA/format/audience), sequenced by impact-by-effort (highest impact, lowest effort first).

## Quality gate

- [ ] Pixel verified before structure.
- [ ] Every creative has a < 3s hook, 9:16.
- [ ] Spark codes secured where used.
- [ ] Refresh cadence scheduled, not hoped for.
- [ ] Diagnosis targets the first failing funnel stage.
- [ ] Tests isolate one variable; order follows impact-by-effort.
