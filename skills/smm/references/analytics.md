# analytics — Analytics: platform metrics, reporting, and the iteration loop.

## Intake

- Objectives and metrics from strategy
- Available platform analytics and tracking links
- Reporting cadence and audience (client, team)
- Current performance baselines
- Default stack: listening inputs from Google Alerts + brand-watch monitoring alongside platform analytics. Fallback: ask which analytics/monitoring tools the client uses if different.

## Deliverable

A social report: performance per platform/pillar versus baseline, top and bottom posts with why, reach-to-outcome funnel (reach → engagement → traffic → conversion), and next-cycle recommendations.

## Procedure

1. Report against objectives, not raw vanity numbers.
2. Tie posts to pillars and formats so you learn what works structurally.
3. Show the funnel: reach, engagement, saves/shares, profile clicks, traffic, conversions.
4. Analyze top AND bottom performers — failures teach the fastest.
5. Separate reach metrics from depth metrics (saves/shares/dwell) — depth predicts value.
6. Turn findings into concrete next-cycle changes (format, hook, timing, pillar mix).
7. Keep tracking links and UTMs consistent so attribution holds.
8. Cover the dark funnel: use branded-search lift as proxy, correlate untracked signals (DMs, word-of-mouth mentions, direct spikes), and score per-channel health separately from attribution.
9. When scope is unbounded ("all posts", "everything about X"), fix query scope, date range, result cap, and output format before planning — never invent defaults.
10. Read per-post depth beyond likes (views, saves, replies) and pull liker/reposter lists as audience signal; for growth reads, baseline followers, sample recent posts for best format/day-time, and recommend only what the measurements support.
11. Verify every numeric claim against the observed metric before publishing — recheck counts, rates, and attributions; a claim that cannot be traced to a measured value is cut, not hedged.

## Quality gate

- [ ] Report is tied to stated objectives.
- [ ] Findings split by pillar/format, not just totals.
- [ ] Full funnel shown, not just likes.
- [ ] Each finding yields a concrete next-cycle action.
- [ ] Dark-funnel proxy (branded search + untracked signals) and per-channel health scored.
- [ ] Tracking links/UTMs consistent across platforms.
- [ ] Every number traced to an observed metric; untraceable claims cut.
- [ ] Small-sample honesty: medians + MAD (never means) on small sets, 10-post floor for pattern claims, and 'no surviving pattern' reported as a finding — never softened into strategy.

## Routing

- Ongoing social-listen execution → growth competitor mode for cadence, thresholds, and the recurring brief.
- Metric-backed proof wording → content copy mode for the claim behind the number.
