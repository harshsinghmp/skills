# copy — Copy: hero, feature, and CTA copy built around one action.

## Intake

- Page type and its single conversion action
- Target reader and the objection the page must remove
- Verified product facts and differentiators
- Voice/tone and any approved claims library
- Default stack: AI agents for first drafts with a human edit pass — or any drafting aid before human review.

## Deliverable

Section-by-section page copy: hero (headline + subhead + CTA), proof, feature/benefit blocks, objection handling, FAQ, final CTA — plus headline variants for testing.

## Procedure

1. Name the one action the page drives (book, buy, sign up, contact).
2. Write 3 hero headline variants: benefit-led, outcome-led, objection-led.
3. Write the subhead that makes the headline concrete and specific.
4. Order sections as a persuasion sequence: hook → proof → features → objections → FAQ → CTA.
5. Write benefit-first feature copy, backed by a real fact each time.
6. Handle the top objections explicitly (price, effort, trust, fit).
7. Write CTA microcopy that reduces friction (what happens next, no risk).
8. Cut every sentence that does not inform or persuade; run a humanize pass.

## Quality gate

- [ ] One primary action drives the whole page.
- [ ] Headline variants provided for testing.
- [ ] Every feature tied to a benefit and a real fact.
- [ ] Top objections addressed explicitly.
- [ ] CTA microcopy lowers friction.
- [ ] Humanize pass run.
