# launch — Launch: announcement copy kit for a product or feature release.

## Intake

- Launch subject (product/feature) and launch date
- Single reader and the one action the launch must drive
- Offer, key messages, and proof (numbers analytics-verified before they enter copy)
- Delivery state read from ops milestone — no launch copy for unshipped scope
- Channels in scope (landing, email, video, social pointer)
- Default stack: docs/slides for the kit — or any format the channels consume.

## Deliverable

A launch copy kit: headline + offer, key messages, channel-ready assets (landing hero, launch email, announcement script/pointer), one CTA per asset, and a ship checklist tied to launch date.

## Procedure

1. Confirm delivery state from ops milestone before writing a word — slipped scope rewrites the kit.
2. Lock the single reader, the offer, and the one action.
3. Verify every number through analytics before it enters copy — no invented metrics.
4. Draft the headline + offer first, then key messages, then channel assets.
5. One CTA per asset; keep voice consistent across channels.
6. Run a humanize pass on AI-drafted prose before delivery.
7. Tie each asset to the launch timeline with an owner.

## Quality gate

- [ ] Delivery state confirmed from ops milestone.
- [ ] Every number analytics-verified, with baseline and timeframe stated.
- [ ] Single reader, offer, and one action explicit.
- [ ] One CTA per asset; voice consistent across channels.
- [ ] Humanize pass run on AI-drafted prose.
- [ ] Each asset has an owner and a ship date.

## Routing

- Delivery state, scope, and change orders → ops milestone (no change orders logged here).
- Numbers and performance claims → analytics reporting.
- Channel execution (social calendars, paid ads) → smm / paidads.
