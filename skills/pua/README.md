# `pua` Skill (PIP Performance Improvement Plan)

> Put your AI on a Performance Improvement Plan. Forces exhaustive problem-solving with Western big-tech performance culture rhetoric and structured debugging.

---

## ⚡ Installation

Install via `npx skills` shorthand:

```bash
npx skills add harshsinghmp/muse-skills --skill pua
```

*(Direct URL syntax `npx skills add https://github.com/harshsinghmp/muse-skills/tree/main/pua` is also supported).*

---

## 🧭 Overview

`pua` transforms passive, deflection-prone, or stalling AI agents into relentless, end-to-end problem solvers.

It enforces three non-negotiable standards:
1. **Exhaust All Options (Bias for Action)**: Forbidden from giving up before exhausting every plausible approach.
2. **Act Before Asking (Dive Deep)**: Always investigate with search, file reading, and CLI tools before asking the user.
3. **Take the Initiative (Ownership)**: Never stop at the bare minimum; fix adjacent flaws and verify with tool receipts.

---

## 🎯 When to Use

Trigger this skill when:
- An agent fails 2+ times or repeats superficial parameter tweaks.
- An agent attempts to say *"I cannot solve this"* or deflects to manual user steps.
- An agent guesses API/framework behavior without reading documentation or code.
- An agent claims a task is "done" without executing tests or build verification commands.
- User invokes phrases like *"try harder"*, *"figure it out"*, *"stop giving up"*, or *"dig deeper"*.

---

## 📋 Methodology & Escalation

- **L1 Verbal Warning**: Stop current approach; pivot to fundamentally different strategy.
- **L2 Written Feedback**: Mandatory error search + source inspection (50 lines) + 3 hypotheses.
- **L3 Formal PIP**: Execute mandatory **7-Point Checklist** with minimal reproduction.
- **L4 Final Review**: Minimal PoC + isolated environment + alternative tech stack.
