Quarterly personal and project strategic retreat facilitator. Conducts multi-scale deep audits of project health, architecture debt, deprecated system purges, Wheel of Life alignment, and next-quarter OKR handoffs across the LifeOS ecosystem.

---

## 🧭 What is this?

Without recurring strategic pauses, software repositories and personal systems accumulate severe **entropy**:
- Dead scripts, zombie dependencies, and unmaintained docs pile up.
- Daily urgency crowds out high-leverage architectural refactoring and TELOS goals.

`periodic-retreat` provides a rigorous 4-phase framework (Retrospective → Debt Purge → TELOS Alignment → Next-Q OKRs) to restore focus and strip away technical debt.
