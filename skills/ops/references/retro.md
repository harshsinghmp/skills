# retro — Retro: blameless review producing tracked process improvements.

## Intake

- Project scope and outcome vs goals
- Timeline and key events
- Team and client feedback
- Metrics (margin, timeline, rework)

## Deliverable

A retrospective: what went well, what didn't, root causes, and a small set of tracked action items (owner + date) that improve the next engagement — plus a reusable lesson.

## Procedure

1. Set the framing: blameless — blame process, not people.
2. Compare outcome to goals: on time, on scope, on margin?
3. Capture what went well and what did not, with specifics.
4. Find root causes for the misses (not symptoms).
5. Agree 2–3 tracked actions with owners and dates — no more than that.
6. Record reusable lessons and update the agency's playbook/templates.
7. Share the outcome with the team and the client where appropriate.
8. Solo: run the retro as a written self-review; the client-facing wins/misses still go in the QBR doc.

## Quality gate

- [ ] Framing is blameless.
- [ ] Outcome compared to goals (time/scope/margin).
- [ ] Root causes found for misses.
- [ ] 2–3 tracked actions with owners and dates.
- [ ] Lessons fed back into templates/playbook.
