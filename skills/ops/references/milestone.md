# milestone — Milestones: tracked delivery, scope control, and change orders.

## Intake

- SOW milestones and deliverables
- Current status per deliverable
- Blockers and dependencies
- Any requested changes since kickoff

## Deliverable

A milestone tracker: status per deliverable (owner, due date, state), a blocker log, and change orders for any scope change — with a client-facing status summary.

## Procedure

1. Create a tracker per milestone: deliverable, owner, due date, status.
2. Review status on a fixed cadence; flag slippage early.
3. Log blockers with owners and the action to clear them.
4. Route any out-of-scope request through a written change order (impact on time/cost).
5. Keep a client-facing status summary current and honest.
6. Archive completed milestones with evidence of acceptance.

## Quality gate

- [ ] Every deliverable has owner, date, and status.
- [ ] Slippage flagged before the due date.
- [ ] Blockers logged with owners.
- [ ] Scope changes have written change orders.
- [ ] Client status summary kept current.
