# vendor — Vendors & subcontractors: score performance, protect margin, cut waste.

## Intake

- Active vendors/subcontractors/freelancers and what they were hired to do
- Spend per vendor and the contract/MSA terms
- Service level / delivery expectations and recent outcomes
- Tooling subscriptions and what each contributes

## Deliverable

A vendor scorecard (reliability, quality, speed, cost, SLA compliance), a spend view by categorized spend, and a consolidation/exit recommendation per vendor — with the tools rationalized against value.

## Procedure

1. Score every vendor against an SLA baseline: on-time %, defect/rework rate, response latency, cost vs market, and contract-compliance (scope, IP, NDAs).
2. Classify risk: critical-path, single-point-of-failure, or commodity/replaceable — the only replaceable class gets a consolidation/exit path.
3. Categorize spend (delivery labor, tooling, subscription), and flag duplicate/underused tooling for consolidation — agencies bleed margin on stacked SaaS.
4. Route the scorecard to a renewal/termination decision per vendor; never auto-renew a low-scoring critical vendor.
5. Ensure the MSA covers: scope of work, IP assignment to the client's project, liability limits, NDA, change-order and exit terms — before relying on any vendor on a client engagement.

## Quality gate

- [ ] Every vendor has an SLA baseline and a score.
- [ ] Risk class assigned (critical / single-point / commodity).
- [ ] Spend categorized; duplicate tooling flagged for consolidation.
- [ ] Renewal decision per vendor, never blanket auto-renew.
- [ ] Critical vendor MSA verified for IP/liability/NDA before client reliance.

## Routing

- Vendor spend/data → `analytics`; margin calls on vendor cost → `growth` (pricing).
- Onboarding a new subcontractor → `ops` onboarding mode.
